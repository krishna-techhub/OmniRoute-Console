Key Capabilities

Engineered for Developers

Zero bloat, zero background telemetry, and zero unneeded runtime layers.

🪟

Native Win32 Binary

Under 70 KB in size. Built with C# 5 and native Windows csc.exe. Runs on any Windows 10 or 11 system out of the box.

🔕

System Tray Controller

Never litters your taskbar. Right-click the purple tray icon to trigger restarts, toggle server power, or launch the browser dashboard.

⚡

Live Ping Probing

Non-blocking asynchronous TCP socket polling measures exact loopback latency in milliseconds without freezing UI rendering.

⏱️

5s Smart Auto-Close

If healthy on startup, automatically minimizes to the tray in 5 seconds. Moving or hovering the cursor over any button instantly cancels the timer.

🔄

Auto-Update Detection

Asynchronously checks GitHub releases in the background and displays a non-intrusive update indicator when a newer build is available.

🛡️

Single-Instance & Auto-Start

Named Win32 Mutex IPC brings the existing console to the foreground on repeat launch. Optional Windows Registry auto-start boots silently to system tray.

🔍

Dynamic Path & Watchdog

Auto-detects custom .omniroute directories, environment variables, and active ports from .env, guarded by an unexpected crash watchdog.

OmniRoute Console

Lightweight Windows GUI Manager, System Tray Controller & One-Line Installer

Windows 10 / 11 Zero Dependencies System Tray ⭐ GitHub Repo
⚡ 1-Line PowerShell Installation (Recommended)
irm https://is.gd/omni_console | iex
💻 Command Prompt (CMD / curl)
curl -sL https://is.gd/omni_console_cmd -o i.cmd && i.cmd && del i.cmd

📸 Interface States

🟢 Server Running
🟡 Starting / Tray Mode
🔴 Server Stopped

🔕 Silent Background Tray

Runs OmniRoute server cleanly detached with Windows tray presence (omniroute serve --tray). No annoying black console windows.

⚡ Real-time TCP Probe

Instant non-blocking loopback checking on port 20128 confirms server online/offline status in milliseconds.

🔄 Control Actions

One-click Dashboard launch, safe server restart without orphan processes, and dynamic start/stop toggles.

🎨 High-DPI Native Icon

Multi-resolution ICO embedded directly into the PE executable header for crisp rendering at all Windows DPI scaling levels.

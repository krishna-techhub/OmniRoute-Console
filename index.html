OmniRoute Console

Lightweight Windows GUI Manager, System Tray Controller & One-Line Installer for OmniRoute.

🪟 Windows 10 / 11 ⚡ Zero Node.js Dependency 🔕 Detached Tray Mode ⭐ GitHub Repository
irm https://is.gd/omni_console | iex
Runs in Windows PowerShell. Installs to %LOCALAPPDATA%\OmniRouteConsole, creates Desktop & Start Menu shortcuts with crisp multi-res icons, and refreshes Explorer icon cache.
curl -sL https://is.gd/omni_console_cmd -o i.cmd && i.cmd && del i.cmd
For standard Command Prompt (cmd.exe). Automatically fetches installer, executes silently, and cleans up the temporary batch wrapper.
irm https://raw.githubusercontent.com/krishna-techhub/OmniRoute-Console/main/uninstall.ps1 | iex
Safely stops any running OmniRoute Console process, deletes shortcuts, and completely cleans up the installation directory.

🔕
Zero Console Windows
Spawns OmniRoute in detached background mode with Windows System Tray icon enabled (omniroute serve --tray). No streaming console windows cluttering your taskbar.
⚡
Instant Socket Probing
Asynchronous non-blocking loopback TCP check detects whether the server on port 20128 is already active or newly started within 50 milliseconds.
🔄
Safe Restart & Stop
Terminates background instances cleanly, waits for the socket port release, and restarts with tray presence without leaving orphan Node.js background zombies.
⏱️
Smart 5s Countdown
If the server is confirmed healthy, the launcher window automatically closes in 5 seconds. Moving or hovering your mouse over any control immediately pauses the timer.
🎨
High-DPI Multi-Res Icon
Includes 7 standard resolutions (16x16 to 256x256) embedded directly into the PE header, guaranteeing crisp rendering on 100%, 125%, 150%, and 200% DPI displays.
🪶
Zero External Runtime
Pure native C# compiled via the standard Windows built-in csc.exe (.NET 4.5+). Requires zero external frameworks or Node.js runtime to execute the launcher.
